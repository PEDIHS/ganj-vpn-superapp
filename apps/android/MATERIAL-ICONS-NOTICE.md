# Google Material Design Icons

The following vector assets used in the GANJ VPN Android profile and storefront
are adapted from the open-source Google Material Design Icons collection:

- ganj_symbol_wallet.xml — account_balance_wallet
- ganj_symbol_history.xml — history
- ganj_symbol_subscription.xml — credit_card
- ganj_symbol_devices.xml — devices
- ganj_symbol_family.xml — groups
- ganj_symbol_appearance.xml — palette
- ganj_symbol_shield.xml — verified_user
- ganj_symbol_support.xml — headset_mic
- ganj_symbol_diagnostics.xml — analytics
- ganj_symbol_account.xml — account_circle
- ganj_symbol_refresh.xml — refresh

Source: https://github.com/google/material-design-icons
License: Apache License, Version 2.0
https://www.apache.org/licenses/LICENSE-2.0

The colors are set by the GANJ application theme at runtime. These vector
icons are not remote-loaded and require no icon CDN or new Android dependency.
